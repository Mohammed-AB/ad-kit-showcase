# Ad-Kit Workbench: guided demonstration

A local creative workflow with saved real image and short-motion outputs. New paid generation is disabled in the default launcher.

## A focused walkthrough

1. **Brief.**
2. **copy.**
3. **layout.**
4. **generate media.**
5. **review.**
6. **export.**

Pause on the evidence at each decision: layout checks; owned image and motion output; reviewable exports.

## Interactive access

The application is available in Mohammed's local Demo Studio. This repository deliberately does not contain a runnable source distribution. A reviewer can inspect the included materials immediately or request a guided limited-demo session through [the portfolio](https://mohammed-ab.github.io/).

## Boundaries

The video is generated short motion, not an avatar performance. Avatar generation is unavailable in this demo. It does not publish ads or spend a campaign budget.
